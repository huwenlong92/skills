# Wiki 版本管理

在评估、生成候选或发布 Wiki 版本前，读取目标仓库 AGENTS.md、standards/versioning.md、standards/portal.md，以及本 Skill 的 repository.md 与 publishing.md。

## 里程碑评估

核对最近正式 Tag 与 main 的 SHA，比较知识文章、主题、迁移和门户工程变化；结合内容价值、专题完整度和验证证据判断是否值得发布。只读评估不得创建 Tag。无正式 Tag 时评估初始基线。无法完整获取差异时明确说明。

## 候选报告

包含比较范围、变更统计、重要成果、建议版本号、发布理由、风险和验证状态。对相同目标 SHA 去重，不反复提醒。候选不构成发布授权。

## 正式发布

必须获得用户对版本和发布范围的明确确认，按目标仓库规范完成构建、快照、并发与敏感信息检查。创建不可变 Tag 和整站历史快照后，分别核对 GitHub、CI、部署及线上访问。失败时保留上次可用版本。

日常知识提交只更新 Latest，不自动打 Tag。知识状态与正式版本号互不混淆。
