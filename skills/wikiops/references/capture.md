# 聊天快速入库

适用范围：用户要求记录当前对话、沉淀方法、保存排障过程、归档决策或摘录材料；或当前任务自然形成可复用技术知识候选，需要在阶段结束提供建议摘要。自动识别不等于写入授权。必须同时读取[知识写入](writing.md)和目标仓库规范；本文件只定义聊天材料如何转为知识，不新增元数据字段或目录约定。

## 自动候选与专题晋升

- 讨论、研发和排障过程中出现已验证的可复用步骤、明确技术取舍或跨项目适用的经验时，允许在当前任务上下文生成候选；未验证的尝试仅作为待核验候选，不得写成成功教程。
- 已有技术主题下出现多个独立知识点、稳定的适用边界及持续维护价值时，才建议晋升专题；单一问题优先普通文章，不机械拆分。
- 候选必须先按 [知识检索与回答](answer.md) 查主题、别名与来源；同主题优先增量更新。项目专有决策归 Foundry，不复制 PRD。
- 仅在任务阶段完成、排障闭环、重要决定确认、话题切换或交接时，有实质候选才简短输出建议归属、证据状态与待授权动作；无候选不输出固定摘要。
- 未经明确记录或持续维护授权，不得因自动识别创建 Wiki 文章、索引、PR 或发布；无法感知未提供的其他会话。

## 确定材料与类型

- 必须以用户指定的消息、链接或当前正在讨论的主题为范围；“记一下这个”必须定位到最近明确的主题，禁止默认导出整个聊天历史。
- 当前对话没有可分享 URL 时，来源必须写为“当前对话”、实际日期和已读范围；禁止伪造会话链接、消息 ID、原话或附件。
- 必须区分用户确认、实际执行证据、外部资料和模型建议。聊天中说“可以”只代表对应方案获准，禁止据此声称命令已经执行或问题已经解决。
- 必须按下表选择结构。同一主题兼具多个类型时允许组合必要章节；主题独立且适用对象不同时必须拆分并互相链接，禁止为了模板数量机械拆篇。

| 类型 | 识别依据 | 必须保留 |
|---|---|---|
| 方法 | 可在相同前提下重复使用的操作 | 结论、适用条件、步骤、验证方式、限制 |
| 排障 | 出现具体异常，存在定位或修复过程 | 症状、环境/版本、证据、排除过程、原因状态、修复结果、复查方式 |
| 决策 | 用户明确选择方案、约束或取舍 | 决策内容、日期、理由、适用范围、未选方案及关键取舍、复议条件 |
| 摘录 | 保存网页、文档或分享中的知识 | 原始来源、作者或机构（材料提供时）、取得日期、已读范围、要点、当前分析与待核验项 |

## 写入流程

1. 必须先提炼准备保存的结论和适用范围，再用标题、关键概念、别名、报错文本或来源 URL 搜索已有文章；禁止只按本次聊天标题判断是否重复。
2. 同主题且适用范围一致时必须增量更新原文，保留原 ID、路径、来源和已确认内容；新的结论与旧文冲突时必须补充日期与证据，禁止静默覆盖。仅当主题独立或原文职责不同才允许新建。
3. 必须按目标仓库规则选择主题和文件名。项目专有的环境/决策必须留在项目上下文；允许同时提炼通用方法并链接原记录，禁止复制产品当前 PRD 到 Wiki。
4. 必须套用下方对应结构并删除无材料支持的空章节。问题尚未解决时必须保留现象、尝试和下一步，禁止为了凑齐模板编造根因、命令输出或成功结果。
5. 必须按[知识写入](writing.md)处理元数据、来源、状态与脱敏。补入已确认的一段内容不自动升级整篇文章的状态；涉及真实环境的命令只作为记录，禁止因入库而重新执行。
6. 必须检查相关主题入口与文章链接；自动生成的门户导航只允许通过真实正文和注册表更新，禁止编辑生成目录。提交方式与并发保护服从仓库协作规则。

## 内容模板

下列是正文结构，frontmatter 必须使用目标仓库定义。标题必须具体，章节只保留材料支持的部分。

### 方法

```md
# 数据库连接排查

结论：先确认目标环境与连接入口，再逐项检查连接参数。

## 适用条件
测试环境的数据库连接失败；数据库类型与客户端版本已知。

## 操作与验证
1. 确认实际目标与连接入口；验证连接参数指向预期环境。
2. 按已取得证据定位失败阶段；未执行的步骤标为待验证。

## 限制与来源
来源：当前对话，2026-10-15；仅记录已讨论的方法，未操作真实数据库。
```

### 排障

```md
# 连接超时排查记录

结论：尚未确认根因，当前只确认连接请求发生超时。

## 环境与症状
测试环境；软件版本未提供。

## 已有证据与尝试
用户报告超时；尚无服务日志和连通性测试结果。

## 待验证项
确认目标地址、网络路径与服务监听状态。

## 来源
当前对话，2026-10-15；未取得日志或附件。
```

### 决策

```md
# 知识入口选择

决策：使用统一主题入口组织已有知识。
日期：2026-10-15；确认依据：用户明确选择该方案。

## 理由与范围
降低重复查找成本；适用于知识导航，不改变原文验证状态。

## 取舍与复议条件
独立入口方案暂不采用；当一个主题形成独立维护范围时重新评估。
```

### 摘录

```md
# 文档检索方法摘录

要点：检索时同时考虑标题、术语别名和原始来源。

## 来源与范围
https://example.invalid/article
取得日期：2026-10-15；只取得摘要，正文与附件未读。

## 当前分析与待确认
完整方法和限制尚未核验，不能把摘要当作全文。
```

反例：用户要求保存排障过程，就把 Agent 提出的修复命令写成“已执行且成功”；只取得摘要却生成完整资料结论；将“归档一下”理解为停用文章。

## 完成标准

必须交付实际文章路径或链接、采用的类型、新建或更新的结果、来源与待确认项，并报告真实提交状态。人工检查结论是否覆盖所选材料、是否混淆用户决定与模型建议、是否存在空章节或虚构证据。已有写入授权时禁止在每次套用模板后再次要求批准。
