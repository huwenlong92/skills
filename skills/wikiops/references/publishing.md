# 门户与发布

适用范围：VitePress 工程、构建脚本、CI、Cloudflare 与私有访问。必须读取目标仓库门户与发布规范。

## 构建

- 必须先查看项目已有构建、校验与部署脚本；有参考实现时必须核对其输入输出与依赖后复用，禁止盲目复制业务专属模型。
- 知识正文是唯一事实源，门户内容必须自动生成；生成文件只允许在工程声明的输出目录，禁止手工维护第二份正文。
- 主题导航与搜索必须来自真实知识目录和注册表；版本信息必须来自真实提交，禁止伪造历史快照。
- 必须锁定依赖并运行工程构建与输出校验；构建中不得输出秘密，禁止上传包含私密正文的公开 CI 工件。

## 私有访问与发布

- 必须先确认仓库私有性、Cloudflare 目标、当前 DNS 与既有 Access 规则；禁止覆盖无关应用、账户级策略或其他站点。
- 必须验证自定义域名、默认域名、预览地址、正文与静态资源均不能匿名取得私有内容；只保护首页或自定义域名不足以通过验收。
- 未完成保护时只允许部署无知识内容的测试壳；禁止先上传私密文档后补访问控制。
- Allow 必须限定用户明确授权的主体，禁止 Everyone 或宽泛 Bypass。凭据只能使用现有授权环境与平台秘密存储，禁止写入 Git。
- 生产部署必须核对最新默认分支 SHA，过期构建必须跳过；部署失败必须保留已验证版本，禁止声称提交就是上线。
- 发布后必须对照线上 build-info 提交信息，并验证匿名拒绝与授权可读。授权身份测试需要用户交互时必须明确尚未验证。

## 完成标准

必须分别报告构建、CI、部署 SHA、域名和访问验收；人工核对匿名入口及附件/搜索资源。缺少授权或 Access 能力时停止私密发布，保留已完成的工程与验证结果。
