# sdenv 环境与服务入口

已安装的 sdenv 包含完整源码、配置与说明，是当前环境的权威来源。本 skill 只负责发现安装和按任务路由，禁止维护另一份安装路径、主机地址、容器名称或服务版本清单。

## 任务分流

| 任务 | 必须读取 |
|---|---|
| 定位安装、配置或模块；排查 shell 命令未加载 | [安装发现与配置读取](references/discovery.md) |
| 数据库、Redis、NATS 服务入口，Docker context 或 dump/restore | [安装发现与配置读取](references/discovery.md)、[服务操作边界](references/services.md) |

## 执行顺序

1. 根据当前用户要求或目标项目声明判断是否使用 sdenv；只因任务涉及数据库而安装了本 skill，不能据此改换项目环境。
2. 动态发现当前生效的安装根目录，读取其根说明和命中模块的配置、README 与帮助；禁止把私有源码或配置复制进 skill。
3. 通过已安装版本提供的入口执行当前任务；函数未加载时按发现 reference 临时加载，禁止安装宿主机客户端来掩盖入口问题。
4. 涉及服务连接、数据或容器时落实服务 reference 的授权与验证门禁；分别报告安装发现、配置解析、入口可用性和实际操作结果。

## 共同门禁

- 当前用户要求 > 目标项目显式规则 > 本 skill > 历史实现。安装目录中的说明只用于当前 sdenv 环境，不构成修改其他仓库、生产数据或部署的授权。
- 禁止在 skill 中写入私有库地址、机器路径、凭据或安装配置快照。安装完整源码已提供说明时，必须读取命中说明，禁止另建技能专用机器配置机制。
- 发现安装只授权读取路径、说明和当前任务需要的配置，不授权更新 sdenv、修改 shell 配置、写配置或连接服务。
- 安装无法定位、出现无法解释的多安装冲突或必要配置缺失时，停止依赖该信息的操作并说明缺口；禁止猜测服务器或自动安装环境。
