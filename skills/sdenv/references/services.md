# 服务入口与操作边界

适用范围：通过 sdenv 定位或操作数据库、Redis、NATS、Docker context，以及执行 dump/restore。操作前必须先完成[安装发现](discovery.md)。

## 帮助与环境选择

- 数据库任务必须先执行 `sd help db`，再按实际帮助读取所需环境与服务子模块帮助；禁止先检查宿主机是否安装数据库客户端，也禁止因为缺少客户端而自动安装。
- 用户未指定环境且项目没有相反声明时，必须选择已安装 sdenv 帮助中存在的 `home` 场景；不存在该场景时必须询问目标环境，禁止构造配置或替换为其他远端。`home` 是场景名称，不证明服务运行在当前机器或具备数据操作授权。
- 服务版本、别名、容器名、端口、默认库和 wrapper 参数必须从当前安装的帮助、配置与实现解析，禁止在本 skill 中维护固定版本速查表。仅当用户或项目声明了默认版本时才按该声明选择；存在多个不兼容版本且无法确定目标时必须询问。
- 必须使用帮助声明的执行入口和等价函数；帮助路径采用空格分层，禁止未经核验把 `sd help db/<service>`、`sd db ...` 或猜测的别名当作有效入口。

以下是动态选择后的命令形态；变量必须来自实际帮助和已确认目标，不能直接使用占位值连接：

```zsh
sd help db
sd help db "$scope" "$service"
db "$scope" "$service" <已核对的客户端参数>
```

禁止把历史环境、容器名称或版本替换进变量后当成已经核验。命令函数必须在发现 reference 确认的同一 shell 上下文执行。

## context 与连接

- 必须先确认目标为开发环境；正式库禁止 AI 直接或间接操作，包括查询、dump 和备份，只允许提供人工执行指导。目标性质不明时必须停止连接并确认，禁止试连后判断。
- Docker context 必须由安装现有的映射入口与配置解析，再读取对应 context 的本地元数据核对。当前安装声明支持时，允许使用 `sdenv-docker context "$scope"`；未提供该命令时必须按当前模块说明查找等价入口，禁止自造命令。
- 禁止改变全局 context、新建 context、硬编码主机地址，或因 endpoint 使用 IP/SSH 就擅自改为 `localhost`。仅当已授权的 wrapper 不支持本次操作时，允许对已确认 context 使用容器内工具。
- 安装发现不授权连接服务；查询、写入、清理、备份和恢复必须分别符合当前任务范围。连通性检查只能使用已确认目标的最小无写入操作，超时执行规则以[安装发现](discovery.md)为准。
- 凭据必须复用已有 wrapper 或受控配置；禁止打印容器环境、完整连接串、密码或 Token，也禁止把认证参数写进源码或 skill。

## Redis 与 NATS

- Redis `PING` 只证明连通，数据操作必须另外确认 DB index、key 前缀及项目归属。禁止为定位入口全库展开 key 或缓存值。
- NATS 必须先查当前安装帮助；没有入口时，只允许在已发现的相关模块中做一次定向搜索。仍缺失时，最多列出一次已确认开发 context 的容器名称与镜像，并检查一个明确匹配的工具容器；没有结果必须报告入口缺失，禁止遍历所有容器试命令。
- 禁止假定 NATS server 容器包含 CLI，禁止把发布消息、消费并确认消息、purge stream 或删除 consumer 当连通性检查。缺少工具时必须说明缺口，禁止自动安装 CLI、创建工具容器或改造 sdenv。

## 数据变更与备份恢复

- 数据结构变更前必须备份并验证恢复，再在隔离开发库验收；共享开发库只允许在已有授权时同步增量迁移，禁止用整库恢复覆盖共享开发库。
- dump/restore 必须读取当前服务 wrapper 帮助，确认格式、参数、容器工具与目标库。禁止假设不同服务或版本的备份格式一致。
- 备份只允许保存到用户确认的受控目录，禁止放入代码仓库、公开目录或覆盖唯一备份；恢复目标必须预先确认为隔离开发库，已有数据时必须先备份并确认覆盖范围。禁止默认添加 `--clean` 等破坏性选项。
- sdkitgo 业务清理禁止触碰 `system` 和 `system_data` schema；仅当用户明确指定其中的精确对象时允许处理，操作前后必须核对非目标对象未变化。
- 本 skill 不授权启停/删除容器、切换其他远端、清空缓存或消息资源、修改 shell 配置及更新 sdenv。实施这些动作必须另有用户明确授权。

## 完成标准

- 实际服务入口、版本和 context 来自本次安装说明与生效配置，未从 skill 中复制固定服务清单。
- 操作目标、开发环境性质及授权范围已确认；没有通过试连生产库或输出秘密发现环境。
- 已区分入口缺失、shell 未加载与连接失败；失败时没有自动安装替代工具或改变 context。
- 有与实际操作匹配的验证结果；dump/restore 必须有受控备份和恢复验证记录。人工检查最小连接命令、数据范围和未实施的操作，禁止把帮助可读描述为服务已验证可用。
