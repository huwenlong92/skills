# 安装发现与配置读取

适用范围：定位 sdenv 安装、读取环境配置、选择模块说明或处理命令未加载。执行这些任务前必须读取本文件。

## 安装发现

1. 必须先检查当前 shell 的 `sd` 入口类型、PATH 中的可执行文件位置及已设置的 `SDENV`。只允许读取这些定位信息，禁止输出完整函数定义或环境变量集合。
2. `sd` 可用时，必须先核对其帮助确认为 sdenv，再使用 `sd path` 获取生效根目录。根目录必须包含可读的 `bin/sd`、`shell/index.zsh` 和根 README；不满足时必须报告入口不匹配，禁止把任意同名命令当成 sdenv。
3. `sd` 不可用但 `SDENV` 或用户/项目明确提供了安装路径时，必须先核对上述文件，再读取该根目录的 README、`bin/sd` 与 shell 入口，按该安装的加载方式使用它。显式路径无效时必须报告错误，禁止退回猜测路径掩盖错误。
4. 仅当当前 shell 没有可用入口且没有有效的显式安装路径时，允许启动一次交互 zsh，检查 `sd` 类型、可执行文件位置及 `SDENV`；入口有效后执行同样的身份和根目录核验。仍无法定位时必须询问安装位置，禁止扫描主目录、磁盘、SSH 主机或网络，也禁止写死候选安装目录轮流试探。
5. 多份安装并存时必须以当前实际加载的 `sd path` 为准；路径与用户指定目标或生效的 `SDENV` 冲突时必须停止并确认目标，禁止混用一份安装的配置与另一份安装的命令。符号链接必须比较解析后的真实路径，不能只按路径字符串判冲突。

以下是入口检查形态；交互 shell 仅在满足上面的退回条件时使用：

```zsh
whence -w sd
whence -p sd
print -r -- "${SDENV-}"
# 确认是 sdenv 后执行。
sd path
sd env path
```

安装发现与入口探测的每条命令必须设置不超过 10 秒的执行超时；超时必须终止该命令及其派生进程，禁止轮询等待或原样重试。执行工具未提供超时时，必须使用带超时和进程组终止的执行包装；禁止假设机器安装了 `timeout`。没有新增信息时，同一任务不得重新开始发现。

## 读取安装提供的配置

- 必须先读取已发现根目录的 `AGENTS.md`（存在时）、README 和 `shell/index.zsh`，按实际源码确认配置路径与加载顺序。禁止把安装根目录假定为工作站源码目录或另找一个“源仓库”。
- 当前安装支持时，必须使用 `sd env path` 获取本机覆盖文件；读取 `SDENV_ENV_FILE`、`SDENV_ENV_FILES` 时只允许读取路径值。基础配置、覆盖文件、附加文件与进程环境的生效关系必须以该安装的 shell 入口为准，禁止仅按某个文件中的值推断最终配置。
- 配置路径由 sdenv 返回或其加载链声明；相对路径必须按该安装的实际解析方式处理。文件尚未创建时必须保留这一事实，禁止为了读取而运行配置写入命令。
- 必须从当前安装的模块声明、`sd help` 和对应 README 定位本次模块，只读取命中的配置键与实现。禁止读取完整私密配置到工具输出，也禁止运行无参数 `sd env`、`env`、`set`、完整 `docker inspect` 或其他凭据转储。
- 必须先从安装说明或源码识别非敏感键名，再定向核对需要的 context、服务版本或入口。仅当已确认键不包含密码、Token、私钥或连接串时，允许使用 `sd env <KEY>` 查询其生效值。不得把返回内容当 shell 代码 `eval`。
- 禁止在 skill、业务项目或公开仓库保存安装配置副本；配置保持在安装现有加载链指定的位置。需要修改配置时必须另有用户授权，并遵守该安装的配置入口，本 skill 的发现流程不执行配置写入。

正向形态：用 `sd path` 定位安装，再用 `sd env path` 定位覆盖文件；读取 shell 入口确认附加配置，最后只解析当前模块所需的非敏感配置。

反例：写死个人安装路径、整份输出本机覆盖文件、复制服务配置进本 skill，或为了找到配置先执行 `sd refresh`。

## shell 未加载

只有根目录已经通过核验、当前任务需要的函数尚未加载，且安装说明允许时，才允许在临时子 shell source 已发现入口。禁止修改 `.zshrc` 或持久化 `SDENV`，禁止安装、更新或同步环境。

```zsh
# sdenv_root 必须来自已经核验的安装发现结果。
zsh -c 'source "$1/shell/index.zsh"; whence -w sd db' sdenv "$sdenv_root"
```

路径必须通过参数传递并加引号，禁止插入动态 shell 源码。后续操作必须使用同一安装及同一配置上下文，禁止通过重新加载另一份 shell 配置切换安装。临时加载最多一次，失败后必须停止并报告入口问题。

## 完成标准

- 有经核验的生效根目录、配置加载链和命中模块说明；发现过程没有依赖个人固定目录或远端地址。
- 能区分未安装/未定位、命令未加载、配置缺失和服务不可达；未通过试连服务判断安装是否存在。
- 人工检查：PATH 单入口、仅设置 `SDENV`、交互 shell 才有入口、多安装冲突、缺失配置及超时场景均按相应分支处理；无依据时停止且不扩大搜索范围。
- 没有输出秘密、复制配置、写配置或更新 sdenv；交付只报告必要路径类别、入口状态和未解决事项。
