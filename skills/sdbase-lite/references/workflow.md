# 开发与验收

适用范围：创建、修改、评审、调试和测试基于本模板的项目时必须读取。

## 技术边界

- 单服务使用 `app/web`、`cmd/web`；数据库为 SQLite，迁移在 `migrations/`，不得套用完整版 PostgreSQL 或多服务空壳。
- Cookie Session 由服务端管理；成功 API 返回裸 JSON，错误为安全消息对象；不得复制业务标识或密钥。
- 只在项目实际具备 SSE 时接入实时服务；默认不添加 Redis、NATS、复杂 RBAC。

## 验证

- 按项目 README 先执行 `make check`，涉及前端嵌入时再执行 `make build`；涉及数据库时必须验证 SQLite 一致性备份和初始化拒绝覆盖。
- 修改前确认项目已有命令和依赖版本，禁止为局部任务升级整套工具链。
- 不自动提交、Push、合并、部署或修改生产数据；涉及危险操作时必须确认范围和恢复方式。

## 完成标准

说明实际运行的测试命令及结果、受影响的功能和未验证范围；禁止将模板示例或接口声明当成已完成的真实业务能力。
