# Execution Verification and Audit V1

适用范围：受控数据库执行前、中、后的检查和审计设计；当前仅允许离线审查。

- 执行前核对目标、权限、SQL、Plan、History、Snapshot、授权与恢复证据，防止 TOCTOU；有并发修改或无法取得独占控制时停止。
- 逐步记录操作身份、步骤顺序、SQL Hash、影响行数、前后结构与业务不变量。审计前置记录失败不得开始 SQL。
- 锁或租约失效必须停止新步骤；已发出的 SQL 需查询真实结果，不能声称自动撤销。
- MySQL/Oracle DDL 可能隐式提交；不允许假定整个 Migration 可事务回滚。
- 验证失败、影响阈值超限、审计写入失败或提交状态未知时进入调查，不自动继续。
- V1 不开发 HTTP Gateway、审批服务或审计数据库，也不提供任何真实执行命令。

完成标准：离线证据可区分准备、授权、执行、验证、失败与恢复；无执行权限外溢。
