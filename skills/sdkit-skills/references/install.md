# 本地安装安全

适用范围：将本管理 Skill 仓库内的 Skill 安装或更新到明确指定的本地 Agent Skills 目录。

## 门禁

- 仅支持本地目录作为来源与目标；不自动执行 pnpx、网络下载或第三方工具安装。
- 安装前必须确认目标是用户明确指定的 Agent Skills 父目录；不允许将目标放在来源 Skill 内。
- install 不覆盖已存在的目标目录，即使文件内容相同也必须显式检查。
- update 仅更新由本工具创建并记录文件哈希的目录；安装记录缺失、源/目标目录存在符号链接、已安装文件发生本地修改或额外文件时必须停止。
- 更新必须采用临时目录和同父目录备份替换；替换失败时必须恢复旧目录。恢复再次失败时必须报告备份位置并保留备份，即使目标路径已经存在也禁止删除备份；仅当新副本替换成功时允许删除旧备份。个人 config.json 不得保存在安装目录，源 Skill 根目录禁止包含工具保留的 `.sdkit-skill-install.json`。
- 安装记录必须同时核对文件哈希和目录集合；额外空目录、记录格式错误或复制过程中发生的源/目标内容变化必须停止替换。
- 同一目标 Skill 的安装与更新必须通过目标父目录的 `.sdkit-<name>.lock` 排他执行；已有锁必须停止，禁止自动删除他人锁。进程异常退出遗留锁时，必须人工确认没有运行中的写入进程、检查目标和备份后，才允许移除该精确锁文件并重试。
- V1 锁仅约束本工具进程；安装期间禁止其他程序编辑来源或目标。V1 不提供断电或进程被强制终止后的自动事务恢复；中断后必须人工核对目标、`.sdkit-stage-*`、`.sdkit-backup-*` 与安装记录，恢复并验证旧副本前禁止删除备份。
- 多 Agent 安装继续使用 README 中的 pnpx skills 官方工作流；本地安装能力不等于验证所有 Agent 的自动发现。

## 完成标准

安装后所有文件与源 Skill 哈希、目录集合一致；更新前和替换前均检测本地修改；异常恢复失败时人工检查报告位置的备份内容仍完整；无隐式 Commit、Push、部署或 CI。
