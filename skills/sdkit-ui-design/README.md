# sdkit-ui-design

跨项目 UI 设计与开发交接 Skill。只处理设计稿、交互状态、响应式与设计复核，不负责实现或发布。

## 使用场景

- “设计一个后台工作台的桌面和移动端页面”
- “根据已有产品 PRD 出一套 UI 设计稿”
- “把这份设计稿整理为 Codex 可执行的交接说明”
- “对比实现截图与设计基线，指出差异”

仅请求编写 Nuxt/Vue/Flutter 代码时使用对应技术栈 Skill；仅请求产品规划或原型发布时使用 Foundry。

## 入口

从 [SKILL.md](SKILL.md) 选择任务对应的 references。无需个人配置或独立 CLI。图片生成能力由当前 Agent 的可用工具决定，Skill 本身不提供图片引擎。

## 交付

默认一份设计稿及简洁设计说明；复杂任务才增加页面清单、交互状态和素材清单。所有路径和存储位置由实际项目规范决定，不假定固定本机目录。
