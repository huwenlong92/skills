# 响应式与可访问性

适用范围：跨桌面、平板、手机设计及可访问性评审时读取。

- 必须根据目标用户设备和设计任务选择视口；不得强制每个小任务生成三端完整设计。
- 布局折叠不得丢失关键操作、状态反馈、语义阅读顺序或造成页面级横向溢出；长表格和代码块可在自身容器滚动。
- 必须考虑触控目标、键盘焦点、对比度、减少动态效果和文本缩放；尺寸以项目组件体系与适用可访问性要求为准，不强制所有项目使用同一像素值。
- 响应式设计必须明确导航在窄屏下的行为，不允许只缩小桌面页面。
- 无法验证实际设备效果时必须标记“设计建议，未进行浏览器验收”。

正向形态：桌面三列内容在窄屏按语义顺序折叠为单列，并保留操作入口。反例：通过缩小字体和隐藏主要按钮强行保持桌面列数。

## 完成标准

目标设备范围、布局变化、导航策略及可访问性关注项可逐项检查。
