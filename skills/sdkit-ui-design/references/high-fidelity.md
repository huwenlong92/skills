# 高保真设计稿工作流

适用范围：用户明确要求静态高保真视觉图、单页设计稿、设计图归档或视觉稿交付时读取。

- 必须先读取已确认 PRD、页面清单、视觉基线及历史候选图；禁止把示例字段、人数、收费、权限和期限视为已确认规则。
- 必须给每个页面稳定 ID，区分页面与弹窗、成功、失败、空状态。
- 用户要求单张独立设备设计稿时必须输出单页，禁止用多屏拼图替代。
- 生成后必须检查页面身份、文案、业务状态、权限、导航和图片可访问性；失败时不得宣称已完成。
- 用户认可的设计稿必须优先进入归档；仅在业务错误或用户要求修订时再次生成。
- 主稿选择必须记录候选来源和人工确认状态；缺失历史原图必须标记 missing，禁止裁切总览图冒充原稿。
- 静态设计图不得冒充可运行交互原型；交付图片及说明不授权修改产品源码。

交付顺序：PRD → 页面/状态清单 → 单页生成 → 业务与视觉复核 → 主稿选择 → 资产 Manifest → 模块 ZIP → 校验。

正向形态：一张活动报名待审核结果图，页面 ID 固定，未通过状态与活动群权限分别标注。反例：把报名提交成功图称为报名审核通过图。

## 完成标准

每张主稿有可访问的源图片、稳定页面 ID、状态、审核结果及对应的实际文件路径；没有执行的视觉或业务验收必须明确标记。
