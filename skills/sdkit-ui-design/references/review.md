# 设计复核

适用范围：评审设计稿或对比设计基线与实际实现截图时读取；已归档图片按 [设计基线归档](baseline.md) 读取真实修订与哈希。

- 必须区分设计评审、文件归档、代码构建与浏览器验收；没有真实证据不得声称通过。
- 必须核对同一 Design ID/Revision 与 SHA-256、视口、主题、语言、确定性内容及关键交互状态；对照布局、导航、组件、颜色、字体、间距与素材。
- 差异分类：轻微渲染差异、局部视觉偏差、结构/响应式阻断、未经批准的业务或信息架构变更；不覆盖 Development Execution 偏差等级。
- 不以单一像素相似度作为唯一通过条件；必须给出设计图片路径、实际截图、差异区域、影响和修复建议。
- 未执行交互不得宣称表单、路由、权限或异常处理通过；设计变更必须创建新 Revision，不得静默改写原图。

正向形态：同一设计修订与浏览器视口截图逐项对比，记录差异与修复。反例：只看首页截图宣布所有页面和交互通过。

## 完成标准

重大差异可追踪到原始设计资产及修订，明确是否需用户确认设计变更，并区分视觉检查与真实交互验收。
