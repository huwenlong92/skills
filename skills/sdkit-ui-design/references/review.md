# 设计复核

适用范围：评审设计稿或对比设计基线与实现截图时读取。

- 必须区分设计评审与实际代码、浏览器验收；没有真实页面证据时不得宣称已完成实现验收。
- 对照同一设计版本、视口、主题、语言及确定性内容比较页面结构、导航、组件层级、配色、字体、间距、素材和关键状态。
- 差异按轻微渲染差异、局部视觉偏差、结构/响应式阻断、未经批准的业务或信息架构变更分类；该分类只用于设计复核，不覆盖 Development Execution 的偏差等级。
- 不以单一像素相似度百分比作为唯一通过条件；必须说明差异影响、截图证据和建议修复范围。
- 未执行交互操作时只可报告视觉评审，不可宣称表单、路由、权限或异常处理已通过。

正向形态：记录设计图与实际截图、同一视口、差异区域、严重度、修复建议。反例：只看首页截图就宣布全部页面和交互通过。

## 完成标准

每个重大差异均可定位到设计基线、页面或组件，并明确是否需要用户确认设计变更。
