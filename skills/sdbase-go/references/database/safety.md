# 数据库操作安全与协作

本文适用于数据库连接、查询、dump、恢复、结构变更、seed、回填、清理和迁移同步。准备调用数据库工具、运行会连接数据库的应用命令，或开始修改表结构及其 model/migration 前必须读取本文。

## 环境与操作权限

- 必须先依据用户确认和项目环境说明区分本地开发库、远端共享开发库与正式库。远端或“线上”只表示部署位置，不自动代表正式库；远端开发库也不等于个人可随意修改的数据库。
- 正式库禁止 AI 直接操作，包括连接探测、只读查询、dump、备份、恢复、DDL、DML，以及通过应用命令、脚本、CI/CD 或其他代理间接操作。AI 只能根据用户提供的结构、脱敏结果和需求编写指导、待审阅脚本、验证步骤与回滚方案，由人审阅并执行。
- 无法确定环境身份时必须停止连接和执行，向用户确认；禁止通过试连疑似正式库来判断其环境。`app.mode=dev`、库名包含 `dev` 或已有可用凭据，均不能单独证明目标是开发库。
- 获准开发不自动代表获准写入远端共享开发库。同步前必须取得针对目标开发库与本次迁移范围的明确授权；正式库不得以“已授权远端同步”为由执行。

## 先备份，再开发结构变更

- 开始结构变更开发前，必须先备份作为开发基线的数据库，记录环境、库名、时间、结构版本、备份范围、文件位置和恢复方法；禁止先改 model、DDL 或运行自动迁移，再补做基线备份。
- 所有结构变更均受此约束，包括新增或修改表、字段、类型、默认值、索引、约束、schema 和分区，禁止以“非破坏性”或“只是加字段”为由跳过。
- 备份必须包含恢复受影响结构与数据所需的内容及依赖。必须确认导出成功、文件可读，并在隔离的本地数据库完成恢复验证；失败或缺少依赖时停止结构开发，禁止把未验证文件当成可恢复备份。
- 新项目尚无数据库时必须记录“无既有数据库及数据”的核验结果，之后才允许在本地创建空开发库；已有数据库不能使用此例外。
- 在已有目标数据库实际执行结构变更前，还必须为该目标保留执行前备份。早期开发基线备份不能代替同步前的最新备份。
- dump 和备份只能保存到访问受控、不会提交到 Git 的备份位置；禁止放入 skill、模板、公开下载目录或日志附件。含敏感数据时必须遵守项目的数据访问与脱敏要求，禁止上传给无关服务或在对话中展开完整数据。

## 多人协作的固定流程

1. **确认基线**：确认远端目标是共享开发库、导出范围和当前结构版本；保留其 dump 作为开发基线备份。
2. **恢复本地**：将 dump 恢复到隔离的本地开发库，验证结构、依赖与关键数据。恢复前确认目标是本地专用库；已有本地数据必须先备份，禁止覆盖其他开发者或其他项目的数据库。
3. **隔离运行**：本地应用、migration、测试、worker 和 crontab 必须使用本地配置；禁止恢复数据后仍连接共享库，或沿用远端消息队列、通知与第三方写入配置产生副作用。
4. **本地开发与验收**：修改 model 和版本化 migration，在本地完成迁移、业务回归、数据完整性和失败恢复验证。禁止直接在共享开发库试错开发结构。
5. **核对并发改动**：同步前重新核对远端开发库的结构版本与本地基线。发现其他开发者已修改相关对象时必须停止同步，合并迁移并基于最新开发库基线重新本地验收；禁止覆盖他人的改动。
6. **授权与备份**：列出目标开发库、允许变更对象、迁移顺序、数据回填范围、停止条件和恢复方案，取得本次同步授权，并对远端开发库完成最新备份。涉及并发写入时必须协调相关开发者和写入入口。
7. **同步与复核**：只执行已在本地验收、且未再修改的迁移及必要回填，核对结构版本、索引约束、数据完整性和关键业务行为；记录执行结果。失败时停止后续步骤，审计已提交变化，再按确认的恢复方案处理。

这里的“同步改动”指受控增量迁移与明确范围的数据变更，禁止把整个本地数据库 dump 回灌远端来覆盖共享数据，也禁止把测试数据和本地账号顺带同步。业务验收通过不能替代迁移范围核对。

迁移入口、DDL 与事务规则见 [migration.md](migration.md)。上述协作流程仅允许对开发库执行；正式库必须改为人工执行指导，禁止 AI 代执行最后一步。

## 验收

- 必须提供环境判定依据；正式库任务只交付指导，不得存在任何 AI 连接或间接执行记录。
- 必须核对结构开发前的基线备份与目标执行前备份，并提供本地恢复验证结果；未验证时明确停止原因。
- 多人协作必须有远端开发库 dump、本地恢复与验收、并发结构核对、同步授权及执行结果记录。
- 必须检查本地所有数据库与外部写入配置已隔离，备份未进入 Git，远端共享数据未被整库覆盖。
- 环境不明、备份失败、基线冲突、验收未通过或同步范围未获授权时，必须停在对应步骤，不得继续远端写入。
