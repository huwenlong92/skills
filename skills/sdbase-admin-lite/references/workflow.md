# 开发与验收

适用范围：创建、修改、评审、调试和测试基于本模板的项目时必须读取。

## 技术边界

- 使用 `src/core`、`src/stores`、`src/adapters`、`src/app` 和 `src/views` 的实际职责，禁止套用 Vab 的 `library` 和复杂动态菜单。
- 认证以服务端 Cookie Session 为准，前端只维护会话显示状态；401 与网络错误不得混淆。
- SSE 默认关闭，只有项目明确配置服务端事件接口才启用；页面订阅必须随作用域清理。

## 验证

- 按项目 README 执行 `pnpm test`、`pnpm build`，并在桌面与窄屏检查路由、认证、错误反馈。
- 修改前确认项目已有命令和依赖版本，禁止为局部任务升级整套工具链。
- 不自动提交、Push、合并、部署或修改生产数据；涉及危险操作时必须确认范围和恢复方式。

## 完成标准

说明实际运行的测试命令及结果、受影响的功能和未验证范围；禁止将模板示例或接口声明当成已完成的真实业务能力。
