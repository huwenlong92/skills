# 开发与验收

适用范围：创建、修改、评审、调试和测试基于本模板的项目时必须读取。

## 技术边界

- 使用项目声明的 Flutter/Dart 版本和 Riverpod、go_router、Dio 实际 API，按功能模块组织代码。
- JWT 凭据必须安全存储并按环境和账号隔离；缓存、草稿及登出清理不得跨账号泄漏。
- 推送、蓝牙和实时连接目前仅有扩展接口；未接入 SDK 时禁止声称功能可用。
- Android/iOS 签名、正式域名、真实设备与商店发布必须另行授权。

## 验证

- 按项目 README 执行 `make check`，平台构建按变更范围执行 `make android` 或 `make ios`；无法运行原生设备验证时明确报告。
- 修改前确认项目已有命令和依赖版本，禁止为局部任务升级整套工具链。
- 不自动提交、Push、合并、部署或修改生产数据；涉及危险操作时必须确认范围和恢复方式。

## 完成标准

说明实际运行的测试命令及结果、受影响的功能和未验证范围；禁止将模板示例或接口声明当成已完成的真实业务能力。
