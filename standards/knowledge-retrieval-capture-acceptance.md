## 验收方法

1. 静态：检查 Foundry/WikiOps SKILL.md 分流、references 相对链接、共享协议入口、写入权限与现有职责是否一致。
2. 真实行为：在具备对应 Skill 和仓库读取权限的 Agent 中，逐项运行代表性场景，记录输入、加载的 Skill、访问的来源、是否写入、响应和模型版本。
3. 负向检查：不得因为关键词触发无关 Skill；不得以静态规则命中代替真实检索结果。
4. 跨 Agent：未运行的 ChatGPT/Codex/Claude 环境必须标记未验证，不能推断一致性。
5. 低请求量：检查单轮复用已读索引、只读取命中正文，未命中才扩大；禁止无关全仓扫描与自动轮询。

## 完成标准

16 个场景逐项记录通过、失败或未执行；静态与真实行为分开报告。必须明确 Skill 发现依赖 Agent 能力，知识候选不会自动跨会话持久保存，任何写入需已有授权。
